# Java Download Manager

## 1. Project Description

Java Download Manager is a command-line application written in Java.
It allows users to download files from URLs and save them locally.

## 2. Features

- Download files from URLs
- Display download progress
- Save downloaded files
- Run downloads in a separate thread
- Maintain download history
- Command-line interface

## 3. Requirements

- Java 17 or later
- Maven 3.8 or later
- Internet connection

## 4. Project Structure

java-download-manager/
├── src/
├── downloads/
├── pom.xml
├── README.md
└── .gitignore

## 5. Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Enter the project directory:

cd java-download-manager

Compile:

mvn compile

## 6. Running the Application

Run:

mvn exec:java

## 7. Using the Application

Select:

1. Download file

Enter the URL.

Enter the desired filename.

The downloaded file will be saved in the downloads directory.

## 8. Download History

Select:

2. Show download history

The application displays previous downloads.
